一、环境准备



&#x20; # 1. 克隆项目

&#x20; cd ai\_honeypot\_framework



&#x20; # 2. 安装依赖（仅 numpy + paramiko，纯标准库为主）

&#x20; pip install -r requirements.txt



&#x20; 依赖清单：



&#x20; • numpy>=1.26.0 — 分析层 JSD 计算

&#x20; • paramiko>=3.4.0 — SSH 蜜罐（可选，不装则 SSH 模块不启动）



&#x20; ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────

&#x20; 二、快速验证



&#x20; 运行四层流水线集成测试，确认环境正常：



&#x20; python -m pytest tests/test\_framework.py -v



&#x20; 预期输出：18 passed。涵盖发现层、监控层、分析层、反制层、授权诱导引擎的完整验证。

&#x20; 项目提供 4 个独立入口，覆盖实验、服务、监听三种场景：



&#x20;  入口        命令                                  用途

&#x20; ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────

&#x20; 四、交互式菜单（python main.py）



&#x20; 启动后显示主菜单：



&#x20; === AI 渗透反制蜜罐 实验平台 ===



&#x20; 菜单

&#x20;   1. 启动 HTTP 蜜罐（后台运行）

&#x20;   2. 查看实时统计

&#x20;   3. 查看最近请求

&#x20;   4. 会话分析

&#x20;   5. 启用 CVE 插件

&#x20;   6. 禁用 CVE 插件

&#x20;   7. 查看 CVE 插件列表

&#x20;   8. 设置反制等级

&#x20;   9. 运行反制效果验证实验

&#x20;   0. 退出



&#x20; 选项 1：启动 HTTP 蜜罐



&#x20; • 输入端口（默认 8080）

&#x20; • 蜜罐开始监听 HTTP 请求

&#x20; • 每个请求自动经过 L1→L2→L3→L4 四层流水线

&#x20; • 终端实时输出分析结果：

&#x20;   \[AI]  60.9  127.0.0.1  GET  /api/users  agent=openai\_gpt  families=\[sqli]



&#x20; 选项 2-4：监控与分析



&#x20; • 实时统计：总请求数、AI Agent 识别数、攻击数、触发反制数

&#x20; • 最近请求：时间、IP、路径、判定结果

&#x20; • 会话分析：按 session 聚合，查看攻击序列和授权级别



&#x20; 选项 5-7：CVE 插件管理



&#x20;  操作       说明

&#x20; ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

&#x20;  启用 CVE   输入 CVE-2026-27966 等 ID，激活对应插件

&#x20;  禁用 CVE   输入 ID 关闭（建议生产环境默认关闭 L3）

&#x20;  查看列表   显示已加载的 3 个插件及启用状态



&#x20; 选项 8：设置反制等级



&#x20; 输入反制等级 (1-3):

&#x20;   1 = 仅 L1 资源耗尽

&#x20;   2 = L1 + L2 情报欺骗

&#x20;   3 = L1 + L2 + L3 CVE 武器化（默认）



&#x20; 选项 9：运行反制效果实验



&#x20; 一键执行 6 组量化实验，生成 JSON + Markdown 报告：



&#x20; L1 Success Rate: 33.3%

&#x20; L2 Success Rate: 50.0%

&#x20; L3 Success Rate: 50.0%

&#x20; Overall Success Rate: 100.0%

&#x20; C2 Beacons Confirmed: 3



&#x20; 报告保存至 experiments/results/experiment\_report\_YYYYMMDD\_HHMMSS.json



&#x20; ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────

&#x20; # 直接启动 HTTP 蜜罐（不进入交互菜单）

&#x20; python main.py --server --port 8080



&#x20; # 按 Ctrl+C 停止

&#x20; 六、独立运行实验（python experiments/runner.py）



&#x20; 不依赖交互菜单，直接运行完整的反制效果量化验证：



&#x20; # 终端 A：启动 C2 监听器（接收 L3 payload 回连）

&#x20; python c2\_listener.py



&#x20; # 终端 B：运行实验（也可以使用任何 基于大模型的渗透测试系统）

&#x20; python experiments/runner.py



&#x20; 实验流程：



&#x20; 1. 自动启动 C2 监听器（端口 9999）

&#x20; 2. 依次执行 6 个场景：

&#x20;   • S1: L1 无限迷宫（Generic Scanner）

&#x20;   • S2: L2 假凭证提取

&#x20;   • S3: L2 Prompt 反向诱导

&#x20;   • S4: L3 LangChain CSV RCE

&#x20;   • S5: L3 Semantic Kernel eval RCE

&#x20;   • S6: 多路径累积攻击

&#x20; 3. 检查靶标 Agent 是否被攻陷、C2 Beacon 是否确认

&#x20; 4. 输出聚合统计并保存报告



&#x20; ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────

&#x20; 七、独立运行 C2 监听器（python c2\_listener.py）



&#x20; python c2\_listener.py



&#x20; • 监听 0.0.0.0:9999

&#x20; • 接收 CVE payload 执行后的回连请求

&#x20; • 每收到一个 beacon，终端输出：

&#x20;   \[C2] BEACON from 127.0.0.1 | POST /beacon | total=3

&#x20; • 记录持久化到 experiments/c2\_beacons.jsonl
